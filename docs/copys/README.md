## Las reglas que gobiernan todo el copy

**1. La IA es el mecanismo. El problema del negocio es el motivo de compra.**
La home vende agencia de IA. Las landings venden el problema de un sector.

**2. No vendemos funcionalidades. Vendemos el problema resuelto.**
Nunca "agente de voz con integración CRM". Sí "cuando sales de la visita, ya
sabes quién ha llamado y qué buscaba".

**3. Si el límite lo pone el cliente, va en el copy. Si lo ponemos nosotros, no
va hasta que exista.**
Que la clínica tenga software con API o no cambia *cómo* se implanta, no *si* se
puede: eso es conversación de la llamada. Pero si el hero promete que
descolgamos el teléfono, alguien llamará al número de demo y no habrá nadie.

**4. La voz está fuera de todos los copys.** No hay proveedor conectado. Cuando
lo haya, se cambian los heroes afectados: es una tarde, no una landing nueva.

**5. Caso real = caso real. Demo = demo.** El único caso documentado es el de
Pilar Márquez (micropigmentación) y **no se traslada a ningún otro sector**. En
el resto, la prueba es la demostración del mecanismo, etiquetada como tal.

**6. Nada inventado:** ni resultados, ni porcentajes, ni estadísticas de sector,
ni integraciones concretas por su nombre.

**7. Cada página tiene su propia psicología.** La marca es la misma; la forma de
comprar, no. Inmobiliaria es racional, dental se compra por confianza,
concesionarios es gestión de cartera. No se calca la estructura de una en otra.
